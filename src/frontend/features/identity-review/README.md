# Identity Review frontend feature

P1A pending-review queue and atomic Contact/Company decision UI. Public entry: `index.ts` (browser-safe); server-only entry: `server.ts`. Loaders and clients runtime-parse strict transport views and render only server capabilities, including per-candidate Link authority. The public reconciliation classifier binds server errors to fail-closed authority loss, refetch, same-request retry or new-request behavior without deriving authority. Hold is non-mutating and remains Pending; Resolve requires complete Contact and Company choices. No client matching, ranking, permission, assignment or tenant authority. Imports, merge, conversion and broad identity workspaces are deferred. Executed evidence lives in the focused frontend boundary, transport, interaction and P1A Playwright suites.
