# Leads frontend feature

Manual P1A Lead inquiry intake plus canonical Lead list, Pipeline, and read-only detail presentation. Public entry: `index.ts` (browser-safe); server-only entry: `server.ts`. Server loaders call only the Leads module public query API and runtime-parse every view through the shared transport schemas before rendering. The browser renders server-produced stages, assignment labels, masked contact fields, capabilities, and navigation without owning Workspace, Role, lifecycle, matching, assignment, or visibility authority. CSV/XLSX, public adapters, conversion, canonical editing, Pipeline mutation, and the legacy Lead editor are outside this slice.
