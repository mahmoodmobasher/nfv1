# Leads frontend feature

Manual P1A Lead inquiry intake plus canonical list-primary Lead presentation, secondary ordered Pipeline board, and read-only detail. Public entry: `index.ts` (browser-safe); server-only entry: `server.ts`. Server loaders call only the Leads module public query API and runtime-parse every view through the shared transport schemas before rendering. The feature composes only `src/frontend/design-system` public components and server-produced stages, assignment labels, masked contact fields, capabilities, and navigation. It does not own Workspace, Role, lifecycle, matching, assignment, visibility, or Duplicates semantics. CSV/XLSX, public adapters, conversion, canonical editing, Pipeline mutation, and the legacy Lead editor remain outside this slice.
