# Leads frontend feature

Manual P1A Lead inquiry intake only. Public entry: `index.ts` (browser-safe); server-only entry: `server.ts`. The feature runtime-validates the versioned transport and never owns Workspace, Role, lifecycle, matching or assignment authority. CSV/XLSX, public adapters, conversion and legacy Lead editing are deferred. Executed evidence lives in the focused frontend boundary, transport, interaction and P1A Playwright suites.
