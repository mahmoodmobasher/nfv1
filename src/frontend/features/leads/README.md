# Leads frontend feature

Manual P1A Lead inquiry intake plus canonical list-primary Lead presentation, secondary ordered Pipeline board, read-only detail, and the bounded LEAD-CONVERSION-01 preview/confirmation flow. Public entry: `index.ts` (browser-safe); server-only entry: `server.ts`. Server loaders call only the Leads module public query API and runtime-parse every view through the shared transport schemas before rendering. The feature composes only `src/frontend/design-system` public components and server-produced stages, assignment labels, masked contact fields, capabilities, and navigation. Conversion consumes only its fresh strict preview for eligibility, existing authorized customer choices, inherited assignment, versions, and atomic effects. It does not own Workspace, Role, lifecycle, matching, assignment, visibility, or Duplicates semantics. CSV/XLSX, public adapters, customer creation during conversion, Delivery creation, Pipeline mutation, and the legacy Lead editor remain outside this slice.
